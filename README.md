# 🌍 Aquecimento Global

Este projeto é um **protótipo educativo** desenvolvido com o objetivo de promover a conscientização ambiental através da informação.  
A página apresenta uma estrutura simples e funcional, servindo como modelo para estudos, testes e documentação acadêmica.

---

## 📘 Estrutura do Projeto

- **Cabeçalho de navegação**
  - Home
  - Blog
  - Conversor
  - Fale Conosco

- **Seção principal**
  - Título: *Global Warming*
  - Slogan: *Promovendo a conscientização ambiental através da informação.*

- **Rodapé**
  - © 2026 Global Warming. Todos os direitos reservados.
  - Protótipo para fins educativos.

---

## ⚙️ Funcionamento

- O site foi desenvolvido utilizando **React**, permitindo a criação de componentes reutilizáveis e maior organização do código.  
- Cada item do menu representa uma funcionalidade:
  - **Blog**: espaço para artigos e notícias ambientais.  
  - **Conversor**: ferramenta para cálculos relacionados ao impacto ambiental (ex.: emissões de CO₂).  
  - **Fale Conosco**: formulário de contato para interação com visitantes.  

---

## 🎯 Objetivo

- Promover **educação ambiental** de forma acessível.  
- Servir como **protótipo acadêmico** para estudos de documentação e teste.  
- Demonstrar a aplicação prática de conceitos básicos de desenvolvimento web com React.  

---

## 🛠️ Tecnologias Utilizadas

- **React** → Framework principal para construção da interface  
- **HTML5** → Estrutura semântica  
- **CSS3** → Estilização e layout  
- **JavaScript (ES6+)** → Lógica e interatividade
